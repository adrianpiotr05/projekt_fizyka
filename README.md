# Wyznaczanie przyspieszenia grawitacyjnego za pomocą wahadła matematycznego

Projekt wykonany w ramach kursu *Wstęp do fizyki*.

Celem projektu było wyznaczenie przyspieszenia grawitacyjnego przy użyciu wahadła matematycznego, kamery smartfona oraz programu Tracker Video Analysis. Dane z nagrania zostały przeanalizowane za pomocą skryptów napisanych w języku Python, a następnie porównane z teoretyczną wartością przyspieszenia ziemskiego.

Repozytorium zawiera kod źródłowy wyznaczający okres, drugi skrypt generujący wykres oraz dane pomiarowe.
